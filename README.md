# 玄学运营知识库

给 AI 用的运营知识库。用途是辅助生成抖音短视频脚本、小红书笔记、公众号文章、私域成交文案、课程与咨询介绍。

不是玄学研究库，也不是玄学 AI 产品。

## 设计逻辑

```
卖什么 → 对谁卖 → 怎么吸引 → 参照什么 → 怎么表达
  01       02        03        04        05
```

### 05_品牌表达规范

三个人设并列，各含 `人设设定.md` / `语言风格.md` / `禁用表达.md`。

| 人设 | 定位 | 主平台 |
|---|---|---|
| 1_专业靠谱经验老手 | 传统文化研究者 | 公众号、课程 |
| 2_温和治愈情感专家 | 情感向陪伴者 | 小红书、私域 |
| 3_幽默赚钱风 | 务实派姐妹 | 抖音 |

`0_通用底线.md` 是三人设共用红线，新增人设时引用即可。

## 用法

Markdown 文件夹直接导入 AI 工作台，按 SOP 调用。调用示例：

```
用 05_品牌表达规范/2_温和治愈情感专家 的人设和语言风格，
针对 02_用户需求与心理/高频问题.md 里的「他是不是我的正缘」写一篇小红书笔记。

结构按该人设 语言风格.md 第六节的五步。
专业判断取自 01_行业专业知识/东玄/2_八字分析/。
遵守 05_品牌表达规范/0_通用底线.md。
```

各人设的 `语言风格.md` 末尾都有对应的调用提示词。

## 待补充

02 - 05 有约 40 处 `[待补充]` 和 `[待核实]`，标记的是需要真实数据的位置：用户原话、平台实测、爆款拆解、案例成稿。

这些内容靠推测填写会降低知识库质量，留空等实际运营数据。

## 内容边界

不提供确定性命运预测、医疗建议、法律建议、投资建议、符咒实操。

`05_品牌表达规范/0_通用底线.md` 写明三条红线：不做绝对预测、不恐吓用户、不制造迷信焦虑。
