# 私域成交案例

卡片格式见 `0_模板与用法.md`。只存你认为好的。

## 这个场景的特点

私域跟前三个平台不是一回事，**不要套 03 的五步结构**。

- 一对一，不需要制造认知差，需要**给确定感**
- 她已经认识你了，不用再建立专业形象，要解决「值不值」和「靠不靠谱」
- 语气是对话，不是发布
- 成交的临门一脚往往不是话术，是**风险感低**：价格透明、流程清楚、知道自己会拿到什么

### 私域五步

```
1. 说出她的具体处境（不是泛化人群）
2. 指出她自己解决不了的原因
3. 说明你能提供什么（具体到形式和交付）
4. 降低决策风险（时长、价格、流程透明）
5. 给一个明确的下一步动作
```

### 存卡片时注意

- **删掉所有个人信息** —— 姓名、生日、时辰、城市、职业、聊天截图里的头像昵称
- 只存你说的部分和必要的处境概括，不要存对方原话细节
- 这是咨询记录，泄露出去是信任问题，也是法律风险

建议补两栏：
- **成交结果**（成/未成/待跟进）
- **卡在哪一步**（未成的更值得存）

## 未成交案例也要存

这个文件夹是唯一**失败案例比成功案例更有价值**的地方。

成交的原因往往说不清（可能她本来就想买），没成交的原因通常很清楚 —— 卡在价格、卡在不信、卡在时机、卡在你讲太多她听不懂。
把卡点记下来，下一次就能避开。
