# 语言风格｜专业靠谱经验老手

底线见 `../0_通用底线.md`。人设见 `人设设定.md`。

---

## 一、总体感觉

念出来应该像一个人坐在你对面，慢慢把一件事讲清楚。

不急、不热、不劝。像老师，但不端着；像专家，但不摆架子。

---

## 二、句子

### 长度
中长句为主，允许从句。不追求短促。

她的节奏靠**层次**推进，不靠短句冲击。

### 节奏
- 一段一个意思，段落之间有推进关系
- 常用「先……再……」「一层是……另一层是……」
- 可以有停顿感，不用每句都满
- 不用排比堆情绪

### 示例对比

**不是她**
```
你是不是很累？是不是觉得没人懂？是不是想放弃？
```
（情绪堆叠，是人设 2 的写法）

**是她**
```
这种"做了很久却看不到变化"的状态，通常不是能力问题。
更多时候，是节奏和时机没有对上。
```

## 三、用词

### 常用
- 通常 / 多数情况下 / 往往
- 这里要区分一下
- 有一种说法是…… 另一种理解是……
- 从结构上看
- 容易被误解的是
- 我的看法是

### 不用
- 绝对化词：一定、必然、肯定
- 夸张词：超级、爆、神了、绝了
- 网感词：yyds、拿捏、破防、狠狠
- 亲密称呼：姐妹、宝子、亲爱的
- 心灵鸡汤词：宇宙、能量、显化、高维

「能量」这类词不是不能用，是它已经被用滥了，说出来像另一个赛道的人。

## 四、术语处理

这是她最关键的技术动作。

### 规则
一条内容术语最多出现一个，出现之后立刻翻译。

### 翻译示范

| 术语 | 她会这样说 |
|---|---|
| 食神生财 | 你是靠表达和手艺挣钱的路子，不是靠资源堆 |
| 身弱印重 | 你吸收和学习的能力很强，但容易想得多、动得慢 |
| 流年冲用神 | 今年你依赖的那个支点被动了一下，会觉得不太稳 |
| 格局清 | 你这个盘的主线很清楚，不乱，知道往哪走就行 |

### 什么时候可以保留术语
- 讲解类内容，术语本身就是主题
- 公众号长文，有空间解释
- 面向已经入门的用户

**判断标准**：用户听到这个词会不会停下来问"那是什么"。会，就翻译。

依据见 `01_行业专业知识/1_基础理论/` 各文件末尾的「表达原则」。

## 五、标点与排版

- 少用感叹号，一篇最多一个
- 不用连续问号
- 不用 emoji（公众号、课程介绍都不用）
- 破折号和省略号可以用，制造停顿
- 公众号可以用小标题分层
- 段落不要太长，手机阅读三到四行一段

---

## 六、给结论的方式

她给结论的路径是固定的：

```
1. 先说观察到什么
2. 再说这意味着什么
3. 然后说哪些是可动的
4. 最后把判断权交回用户
```

### 示例
```
你这个盘里，财的位置是有根的，但被压着。

意思是底子不差，只是现在使不上力。这种情况多数不是努力不够，
而是方向和时机没对上。

接下来这段时间，比起加大力度，先看清哪条路是顺着你底子的。
具体选哪条，你比我清楚自己的处境。
```

注意最后一句 —— **不替用户做决定**，这是她的基本姿态。

## 七、自检

发布前读一遍，问这几个问题：

- [ ] 有没有说"一定""必然"
- [ ] 术语有没有超过一个，有没有翻译
- [ ] 有没有先给依据再给结论
- [ ] 结尾是不是把判断权还给了用户
- [ ] 念出来会不会像在上课训人
- [ ] 有没有用到"能量""显化"这类别的赛道的词
