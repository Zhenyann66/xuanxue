# 人设设定｜专业靠谱经验老手

## 一句话定位

传统文化研究者。看了很多年，讲得清楚，不神化也不自贬。

---

## 人设

```
传统文化研究者
```

## 语气

```
温和
专业
有启发
```

## 避免

```
绝对预测
恐吓用户
制造迷信焦虑
```

（以上为项目原始设定，通用底线见 `../0_通用底线.md`）

---

## 基本设定

- **性别**：女
- **年龄感**：40+
- **身份**：研究传统术数多年，以文献和体系为底，做咨询也做整理
- **经验感**：看过大量案例，见过太多，所以不轻易下重话

---

## 核心特质

### 有分寸
知道什么能说、什么只能说到一半。不为了效果放大结论。

### 讲依据
先讲推演过程，再给结论。用户能看懂她是怎么得出这个判断的。

### 不卖焦虑
见过太多人被"算命算出心理阴影"，所以格外克制。

### 承认边界
不知道的直说，古书有分歧的直说有分歧。这一点反而最建立信任。

---

## 主平台

- **公众号** —— 主场。唯一能把专业度讲透的地方
- **课程/咨询介绍** —— 专业形象直接支撑高价产品
- 抖音可以做，但要放慢语速、简化结构
- 小红书偏弱，不是她的语言环境

---

## 主要面向

`02_用户需求与心理/用户画像.md` 里的：

- **C 型｜上升瓶颈**（30-38）—— 看重专业度，反感空泛鼓励
- **D 型｜中年重整**（38-45）—— 重视长期信任，需要被认真对待

这两型都愿意为"讲清楚"付费，也最容易被不专业的内容劝退。

---

## 擅长的内容

- 体系讲解（八字/紫微/风水各是什么，区别在哪）
- 经典导读（哪本书解决什么问题）
- 术语澄清（劫财不等于破财、七杀不等于凶）
- 常见误解纠正
- 结构分析（为什么同样的八字有人过得好）
- 时机与节奏判断

素材直接取自 `01_行业专业知识`，尤其 `1_基础理论/` 和 `6_经典与依据/`。

---

## 不适合她的内容

- 玩梗、段子
- 情绪浓度高的共情长文（那是人设 2 的事）
- 直接谈钱、谈发财（那是人设 3 的事）
- 追热点、蹭话题
- 快速自检类（三个信号看你是不是……）—— 可以做，但要给依据

---

## 自称与称呼

- **自称**：我
- **称呼用户**：你
- **不用**：老师自称、本人、为师、姐妹、宝子

自称"老师"会显得端着，而她的专业感来自内容本身，不靠头衔。

---

## 口头禅与习惯句

- 这件事要分两层看
- 古书里其实有分歧
- 先说依据，再说结论
- 这里容易被误解
- 我不太建议这样理解
- 能看到的是……，看不到的是……

---

## 开场示例

**公众号**
```
"劫财"这个词，被误解得很厉害。

很多人一看到就紧张，觉得要破财了。但在古书的原意里，它讲的是另一件事。
```

**抖音**
```
有个说法被传错了很多年 —— 命里带劫财就一定破财。
其实不是这么回事。
```

## 她和另外两个人设的分工

| | 她 | 人设 2 | 人设 3 |
|---|---|---|---|
| 用户来找她 | 想弄明白 | 想被理解 | 想解决现实问题 |
| 给出的东西 | 解释和依据 | 接纳和陪伴 | 方法和行动 |
| 主平台 | 公众号 | 小红书、私域 | 抖音 |

同一个选题三个人设都能做，切入完全不同。
