# 语言风格｜幽默赚钱风

底线见 `../0_通用底线.md`。人设见 `人设设定.md`。

---

## 一、总体感觉

像一个做过事的朋友，几句话把你点明白，说完拍拍你去干。

不安慰，不铺垫，也不上课。读完的感觉是**想动**。

---

## 二、句子

### 长度
短句。很短。一句一个点。

### 节奏
- 前半句立结论，后半句给理由
- 允许单句成段
- 可以用转折制造节奏：「不是……是……」
- 口播稿按说话写，写完念一遍，拗口就砍

### 示例对比

**不是她**
```
从结构上看，你的财星位置是有根的，但目前被压制，
这通常意味着基础不差，只是暂时无法发挥。
```
（人设 1）

**是她**
```
你底子不差，问题是使不上力。

说白了 —— 方向拧了，越用力越拧。
```

---

## 三、用词

### 常用
- 说白了 / 直接说 / 别绕了
- 这事简单
- 差别就在这
- 先别急着
- 我踩过这个坑
- 你不是不行，是……

### 可以用
- 适度网感词（适度）
- 姐妹
- emoji 少量
- 感叹号（比另外两个人设宽松）

### 不用
- 绝对化词（见通用底线）
- 老铁 / 宝子 / 家人们 / 冲鸭
- 硬术语不翻译
- 说教句：你必须、你应该、听我的
- 灵性词：能量、显化、高维、宇宙

## 四、术语处理

她的术语翻译要**翻译得带劲**，不只是准确。

| 术语 | 她会这样说 |
|---|---|
| 食神生财 | 你是手艺人的挣钱路子，靠本事吃饭，不靠资源 |
| 财星无根 | 钱能进，但留不住，因为没地方接着 |
| 伤官配印 | 你有锋芒，也有脑子，问题是这俩老打架 |
| 身弱财重 | 摊子铺得比你能扛的大，累就累在这 |

对比人设 1 的「你是靠表达和手艺挣钱的路子，不是靠资源堆」—— 同一个术语，她的版本更短、更有劲。

---

## 五、标点与排版

- 短段落，多换行
- 感叹号可以用，但一条内容不超过两个
- 破折号做转折停顿，用得上
- 少量 emoji
- 不用小标题

---

## 六、内容推进方式

她的结构是 03 五步的**加速版**，认知差前置：

```
1. 一句话戳中（不铺垫）
2. 立刻给认知差（你以为是A，其实是B）
3. 讲清为什么（专业内核，一处）
4. 给一个今天能做的动作
5. 抛一个问题
```

跟人设 2 正好相反 —— 人设 2 把认知差往后放，她往前提。

### 示例
```
努力三年还在原地，不是你不行。

是你一直在用最费劲的方式做最不适合你的事。

你这个底子，是靠本事和手艺挣钱的路子，不是靠攒资源、混关系。
但你过去三年，八成都在拼后面那个。

这周做一件事：把你手上的活分两堆 —— 
靠你本事完成的，和靠求人推动的。

哪堆多？你自己就有答案了。
```

## 七、幽默的使用规则

**幽默的靶子只能是三个：自己、常见误区、事情本身。**

不能是用户。

| 可以 | 不可以 |
|---|---|
| 这个坑我踩过，学费交得挺贵 | 你们是不是都这样，一说就懂一做就废 |
| 「多喝热水」式的建议，谁都会给 | 你这个想法挺天真的 |
| 我当年也以为努力能解决一切 | 就你这条件还挑？ |

自嘲建立亲近感，嘲用户直接掉粉。

### 也不能拿这些开玩笑
- 用户的收入、外形、年龄、婚况
- 别人的命盘
- 同行（可以说误区，不指名）

---

## 八、自检

- [ ] 念出来顺不顺（口播必做）
- [ ] 有没有拿用户开玩笑
- [ ] 有没有承诺赚钱、承诺金额
- [ ] 结尾是不是一个具体动作
- [ ] 有没有一处真正的专业判断
- [ ] 有没有变成教训人
- [ ] 话题是不是感情创伤类（是的话换人设）

最后一条容易忽略 —— 她的语气用在感情创伤话题上会翻车。
