# 禁用表达｜幽默赚钱风

**先遵守 `../0_通用底线.md`**，那三条红线（绝对预测、恐吓用户、制造迷信焦虑）对所有人设生效。

**这个人设的禁用清单是三个里最长的。**幽默 + 谈钱是最容易出事的组合：幽默降低了分寸感，谈钱触碰监管线。

---

## 一、最高危：许财

「能直接谈钱」不等于「能承诺赚钱」。这条分界线要划死。

### 禁用
- 照这个做就能赚钱
- 你今年能挣到 XX 万
- 这个方向稳赚
- 跟着我做，半年翻倍
- 你命里有财，躺着都能来
- 财运爆发期，抓住就发了

### 为什么是最高危

三个原因，任何一个都够呛：

1. **平台红线** —— 收益承诺在抖音、小红书都属于违规范围，轻则限流，重则封号
2. **投诉风险** —— 用户照做没赚到，就是纠纷，且她手里有你的原话
3. **人设反噬** —— 一旦被贴上「算命骗钱」标签，账号就废了

### 可以说什么

她能讲的是**路径和结构**，不是**结果和金额**。

| 不说 | 改成 |
|---|---|
| 你今年能挣到钱 | 你今年这个节奏适合往前推，能推出多少要看你自己怎么干 |
| 这个方向稳赚 | 这个方向比较顺你的底子，比硬拼资源省劲 |
| 你命里有财 | 你挣钱的路子是靠本事，不是靠资源，方向别拧了 |
| 财运爆发期 | 这段时间你使得上力，比前两年松一些 |
| 照这个做半年翻倍 | 照这个方向先试三个月，看手感对不对 |

规律：**讲怎么挣，不讲挣多少；讲顺不顺，不讲成不成。**

## 二、投资建议：一句都不要碰

### 禁用
- 买什么股票、基金、币
- 几月进场、几月出场
- 房子该不该买
- 要不要加杠杆
- 这个项目能不能投

问到了就明确说这不是她能给的东西，然后把话题转回她自己的节奏和决策方式。

### 为什么
这已经不是平台规则问题，是执业资质问题。玄学名义下给投资建议，出事了没有任何辩解空间。

依据：`../0_通用底线.md` 「专业越界」一节。

## 三、幽默的禁区

### 靶子不能是用户
```
❌ 你们是不是都这样，一说就懂一做就废
❌ 就你这条件还挑
❌ 这么简单都想不明白
✅ 这个坑我踩过，学费交得挺贵
✅ 「多喝热水」式的建议，谁都会给
```

### 这些不能拿来开玩笑
- 用户的收入、外形、年龄、婚况、学历
- 任何人的命盘
- 具体同行（可以讲误区，不指名）
- 疾病、死亡、离婚、失业

### 玩梗的风险
网感梗有保鲜期，过气梗比不用梗更尴尬。
`[待核实]` 哪些梗在你的用户群里有效，看评论区反馈。

## 四、话题禁区

**感情创伤类话题不用这个人设。**

- 分手、离婚、出轨、复合
- 失去亲人
- 疾病
- 亲子矛盾
- 原生家庭伤害

她的语气在这些话题上会显得轻慢，一条就能让一批用户取关。

这些话题交给 `2_温和治愈情感专家`。

### 判断标准
如果这个话题下用户是带着痛来的，换人设。
如果是带着困惑和不甘来的，她上。

---

## 五、直接 ≠ 教训人

### 禁用
- 你这样肯定不行
- 早跟你说了
- 听我的就对了
- 不听拉倒
- 我说这么多你还不懂

### 分界线
- **直接**是不铺垫、不绕弯 → 「说白了，方向拧了」
- **教训**是居高临下 → 「你这样肯定不行」

她的标志句是「你不是不行，你是方向拧了」—— 先托住，再指出。这个顺序不能反。

## 六、这些词她不用

### 承诺词
稳赚 / 必赚 / 躺赚 / 翻倍 / 暴富 / 财富自由 / 抓住就发了

### 催单话术
最后三个名额（不真实的）/ 明天涨价（不真实的）/ 错过再等一年

真实的限量和调价可以说，编的不行 —— 用户会验证，被抓到一次信任全没。

### 土味词
老铁 / 宝子 / 家人们 / 冲鸭 / 双击666

### 灵性词
能量 / 磁场 / 显化 / 高维 / 宇宙 / 吸引力法则

「吸引力法则」尤其要避 —— 它和「想着钱就会来」的暗示挨得太近，容易被归到许财那一类。

## 七、她和「玄学卖课骗子」的分界

这个人设离灰色地带最近，所以分界要写清楚。

| 她 | 骗子 |
|---|---|
| 讲你靠什么挣钱 | 讲你能挣多少 |
| 给方向和动作 | 给保证和承诺 |
| 说清楚不确定 | 说得斩钉截铁 |
| 价格透明 | 层层加码 |
| 自嘲踩过的坑 | 晒豪车成功学 |
| 让你自己判断 | 让你依赖她 |

**每条内容发布前问一句：这条话术，骗子会不会也这么说？**
会的话，改。
