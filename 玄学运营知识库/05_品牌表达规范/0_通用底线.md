# 通用底线

## 这份文件做什么

三个人设共用的红线。人设可以差别很大，这几条不能破。

放在这里而不是抄进每个人设，是为了改一次就全部生效。新增人设时，`禁用表达.md` 第一行写「先遵守 `0_通用底线.md`」即可。

---

## 一、三条红线

来自项目原始设定，也是 `01_行业专业知识/6_经典与依据/6.5_安全边界与对外定位.md` 的口径：

### 1. 避免绝对预测
不说「一定会」「必然」「肯定发生」。
讲倾向、讲结构、讲节奏，把判断空间留给用户。

### 2. 避免恐吓用户
不用后果施压，不制造「不处理会怎样」的恐惧。
指出容易卡住的地方可以，但要同时给可动空间。

### 3. 避免制造迷信焦虑
不把玄学说成决定一切的开关。
不让用户觉得离了你就过不好，不培养依赖。

## 二、具体禁用

### 绝对化
- 一定 / 必然 / 肯定 / 百分百
- 注定 / 命中注定如此，改不了
- 照做必成 / 包准 / 保证应验

### 恐吓式
- 今年有大劫
- 不处理会影响一辈子
- 这个八字婚姻必败
- 再不调整就来不及了

### 越界承诺
- 改命 / 转运保证
- 指定金额的财运预测
- 具体到日期的事件预言
- 生死、重病、灾祸的断言

### 专业越界
- 医疗建议（吃什么药、治什么病）
- 法律建议（要不要起诉、怎么打官司）
- 投资建议（买什么、几月进场）
- 符咒实操指令

### 制造压力的销售话术
- 最后 X 个名额（如果不是真的）
- 明天涨价（如果不是真的）
- 不买会错过时机

## 三、替代说法

| 不说 | 改成 |
|---|---|
| 你今年一定有变动 | 今年这个位置被动了，变动的可能性比往年高 |
| 这段感情注定没结果 | 这段关系目前是靠一方在撑，这种结构不容易长久 |
| 不调整会很麻烦 | 这里容易卡住，早一点看到会好办一些 |
| 你必须找我看 | 这类情况自己看容易漏掉一层，想细看再找我 |
| 照这个做就能发财 | 这个方向比较顺你的底子，能不能起来还要看你怎么做 |

规律：**把断言换成条件句，把承诺换成倾向，把恐吓换成提醒。**

## 四、三个人设共用的表达原则

1. **术语必须翻译** —— 一条内容术语不超过一个，出现了立刻说人话
2. **讲依据** —— 说结论之前说为什么，这是专业和摆摊的区别
3. **把决定权交回用户** —— 给判断依据，不替她做决定
4. **不评判她的选择** —— 不劝和不劝分，不说她的选择错了
5. **承认不确定** —— 不知道就说不知道，比硬答更可信

## 五、人设可以不同的地方

底线之上，这些允许差别很大：

- 语气松紧
- 句子长短
- 能不能开玩笑
- 情绪浓度
- 能不能直接谈钱
- 自称和称呼
- emoji 和标点习惯

**换句话说：怎么说可以变，说什么不能破。**

## 七、新增人设的做法

建文件夹 → 放三个 MD：

- `人设设定.md` —— 她是谁
- `语言风格.md` —— 她怎么说话
- `禁用表达.md` —— 她不说什么（第一行引用本文件）

然后在上面的清单里加一行。
