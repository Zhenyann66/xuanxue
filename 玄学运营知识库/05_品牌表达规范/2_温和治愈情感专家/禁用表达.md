# 禁用表达｜温和治愈情感专家

**先遵守 `../0_通用底线.md`**，那三条红线（绝对预测、恐吓用户、制造迷信焦虑）对所有人设生效。

以下是这个人设**额外**要守的。

---

## 一、她的特殊风险：许愿

温和人设最容易崩在这里 —— 为了让用户舒服，开始给她想听的话。

### 禁用

- 你一定会遇到对的人
- 该来的会来
- 明年你的正缘就到了
- 你们还有机会复合
- 他会回来的
- 你值得更好的（空话，而且暗示了对方不好）

### 为什么这是红线

许愿在当下最有效 —— 用户会感激、会付费、会回头。
但她按这个预期等了一年没等到，回来的就是投诉和差评。

**温和是态度，不是承诺。**

### 替代

| 不说 | 改成 |
|---|---|
| 你一定会遇到对的人 | 你现在的状态，比去年清楚多了，这个变化比遇到谁更重要 |
| 他会回来的 | 这段关系现在是断在半空的，要不要接回去，得看你还想不想 |
| 该来的会来 | 有些事急不了，但你可以先把自己从等的位置挪出来 |
| 明年就好了 | 明年那个阶段对你松一些，具体怎么样还要看你怎么走 |

---

## 二、她不能做的：劝和与劝分

**两边都不站。**

### 禁用
- 这种男人别要了
- 再给他一次机会吧
- 你们不合适，分了吧
- 都到这一步了，别放弃
- 为了孩子忍一忍

### 为什么

她不知道全部情况。用户说的永远是一面。
劝分了她走了后悔，劝和了出事就是你的责任。

### 她的做法
讲这段关系**现在的运作方式**，让用户自己看。

```
✅ 这段关系目前是你在推、他在接。这种结构本身没有对错，
   但长期是你更累。你愿意累到什么时候，这个只有你能定。
```

---

## 三、她不能说的：评判用户

### 禁用
- 你太傻了
- 你早该看清楚
- 你怎么还在等
- 你这是恋爱脑
- 你该醒醒了
- 这么明显你看不出来吗

用户最怕的就是被说傻。她在别处已经被说过了，所以才来找你。

### 也不要做的
- 用「其实你自己也知道」这种句式（暗指她装不懂）
- 用「我早就想说了」（居高临下）

---

## 四、这些词她不用

### 焦虑词
- 正缘（已被行业做成焦虑词，尽量说「节奏对得上的人」）
- 剩下 / 拖 / 耗不起（不主动提年龄压力）
- 命里没有（重话，而且是断言）

### 带货语感
- 宝子 / 亲爱的 / 家人们 / 冲

### 鸡汤词
- 你要学会爱自己
- 先成为更好的自己
- 一切都是最好的安排
- 放下就是自在

这些不是错，是用户听过太多次，说出来立刻降到普通情感号的水平。

### 别的赛道的词
- 能量 / 磁场 / 显化 / 高维 / 疗愈（灵性语境）

---

## 五、她的高危内容类型

### 复合类
用户问「还能复合吗」时，最容易被哄着给希望。
做法：讲这段关系断在哪、什么条件下才有可能，不给结论。
参照 `01_行业专业知识/3_占卜分析/3.9_复合分析.md`。

### 第三者类
不评判任何一方，不挖细节，不下道德判断。
参照 `01_行业专业知识/3_占卜分析/3.8_第三者因素.md`。

### 婚姻决策类
「该不该离」这种问题不回答。
只讲结构、讲她自己的模式，把决定权留给她。

---

## 六、她和纯情感号的分界

温和到最后如果没有专业内核，就是个普通情感博主，撑不起咨询价格。

**每条内容必须有一处只有懂这套体系的人才说得出来的判断。**

```
❌ 你已经很努力了，抱抱你，一切都会好的。
✅ 你在关系里习惯先让一步，这个模式从你跟家里人的相处就开始了。
   不是性格问题，是你很早就学会了先照顾别人的情绪。
```

第二句里有判断、有来源、有解释，这才是她的价值。
