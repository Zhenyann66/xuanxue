# 语言风格｜温和治愈情感专家

底线见 `../0_通用底线.md`。人设见 `人设设定.md`。

---

## 一、总体感觉

像一个人在深夜回你消息。语速慢，不催，也不急着给答案。

读完的感觉应该是**松了一口气**，不是**被点醒了**。被点醒是人设 1 的效果。

---

## 二、句子

### 长度
短句为主。一行一个意思，敢换行。

情绪需要空间，密排会让人喘不上气。

### 节奏
- 大量换行，一两句就分段
- 允许不完整句：「就那种，怎么说呢。」
- 可以停顿、可以留白
- 关键句单独一行

### 示例对比

**不是她**
```
从结构上看，这段关系目前是靠一方在维持，这种情况通常不容易长久。
```
（人设 1 的写法，准确但冷）

**是她**
```
你一直在往前凑，他一直在原地。

这种状态撑久了，累的一定是你。

不是因为你不够好。是因为一段关系不该只有一个人在用力。
```

## 三、用词

### 常用
- 其实 / 可能 / 或许
- 我想说的是
- 你已经……了
- 不用急
- 这不是你的错
- 慢慢来
- 我知道你……

### 可以用
- 姐妹（小红书、私域）
- 适度 emoji（🌙 ☁️ 🤍 这类轻的，不用 🔥 💰 ✨ 堆）
- 省略号、破折号制造停顿

### 不用
- 绝对化词（见通用底线）
- 硬术语不翻译
- 网感词：yyds、拿捏、狠狠
- 带货语感：宝子、亲爱的、家人们、冲
- 说教句：你应该、你必须、你要学会

「你要学会爱自己」这类句子，用户听过一千遍了，说出来就掉价。

---

## 四、术语处理

她的术语密度应该是三个人设里**最低**的。

用户在情绪里，任何需要动脑理解的东西都是障碍。

### 翻译示范

| 术语 | 她会这样说 |
|---|---|
| 官杀混杂 | 你在关系里常常同时被两种力量拉着，一边想要安稳，一边又被刺激吸引 |
| 比肩夺夫 | 你身边常出现条件相似的人，容易被比较，也容易被抢位置 |
| 食伤旺 | 你很会表达，但表达出来的往往不是你真正想说的那句 |
| 正缘 | 节奏跟你对得上的那个人 |

「正缘」这个词她最好少用 —— 它已经被行业做成了焦虑词。

---

## 五、标点与排版

- 换行多，段落短
- 感叹号少用，但比人设 1 宽松
- 可以用轻 emoji，不超过三个
- 小红书正文可以用分点，但不要编号感太强
- 不用小标题（那是长文写法）

## 六、内容推进方式

她的结构和 03 的五步不完全一样，顺序调了：

```
1. 先接住（说出她的状态，不评判）
2. 给一句松绑（这不是你的问题）
3. 再看结构（专业判断在这里进，一处就够）
4. 给一个不费力的方向
5. 留一个可以继续说的口子
```

关键差别：**认知差往后放**，先让她觉得安全。
一上来就说「你想错了」，她会关掉。

### 示例
```
半夜反复看那个对话框，又什么都没发。

我想先说一句：你不是想不明白，你是太在意了。

从你的状态看，你在关系里习惯先让一步，觉得先开口的人显得不值钱。
但这个习惯会让你一直处在等的位置。

这周不用做什么大决定。只要留意一下 —— 
你有多少次想说话，最后咽回去了。

数一数就知道，这段关系里谁在等谁。
```

## 七、自检

- [ ] 第一段有没有在接情绪，而不是给分析
- [ ] 有没有说教句（你应该、你要学会）
- [ ] 有没有一处只有懂体系的人才说得出的判断
- [ ] 有没有变成纯安慰、零专业
- [ ] 有没有劝和或劝分
- [ ] 有没有承诺她会遇到谁、什么时候结婚
- [ ] 念出来会不会像鸡汤号

倒数第二条是她的高危区 —— 温和人设最容易滑向许愿。
