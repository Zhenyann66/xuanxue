# 内容结构

## 这份文件做什么

标题拉人进来，钩子留住人，结构决定她看完之后会不会**点赞、收藏、留言、私信**。

没有结构的内容就是聊天，聊完就散了，不产生任何转化。

**标记说明**：`[待补充]` = 需要真实案例填的坑。

---

## 一、爆款结构

```
1. 引发共鸣
2. 制造认知差
3. 提供解释
4. 给解决方案
5. 引导互动
```

这五步是一条完整的心理路径，顺序不能乱：

| 步骤 | 用户心里在想 | 这一步的任务 |
|---|---|---|
| 1 引发共鸣 | 说的是我 | 让她停下来 |
| 2 制造认知差 | 原来不是我以为的那样 | 让她意识到自己看漏了 |
| 3 提供解释 | 这个说法有道理 | 建立专业信任 |
| 4 给解决方案 | 我可以做点什么 | 从情绪转向行动 |
| 5 引导互动 | 我想问问我自己的情况 | 完成转化 |

**少哪一步会怎样**

- 少 1 → 没人看
- 少 2 → 像正确的废话
- 少 3 → 像算命摊，不专业
- 少 4 → 说得很准，但没用
- 少 5 → 数据好，没转化

## 二、逐步拆解

### 第 1 步｜引发共鸣

**做什么**：说出她的处境，不解释，不评判。

**素材**：`02_用户需求与心理/用户痛点.md` 的情绪底色栏

**关键**：具体。不是"你很焦虑"，而是"你反复点开对话框，又删掉"。

**常见失败**：太笼统，谁都适用，等于谁都不适用。

---

### 第 2 步｜制造认知差

**做什么**：给一个她没想过的角度，推翻她原本的归因。

**常用转折句**
- 但这件事，可能不是你想的那样
- 问题不在努力不够，在时机
- 你一直在解决错的那个问题

**关键**：认知差必须是真的新，不能是包装过的常识。

**常见失败**：以为"要放下"是认知差 —— 她听过一百遍了。

---

### 第 3 步｜提供解释

**做什么**：用专业框架解释为什么，这是你和普通博主的分界线。

**素材**：`01_行业专业知识` 全部内容

**关键**：讲结构，不讲术语。

对照一下：

| 不要这样 | 要这样 |
|---|---|
| 你食神生财，财星有根 | 你是那种靠表达和手艺赚钱的人，底子是稳的 |
| 今年流年冲了你的用神 | 今年你依赖的那个支点被动了一下，会觉得不稳 |
| 你身弱印重 | 你很会吸收学习，但容易想得多、动得慢 |

**原则**：术语一条内容最多出现一个，出现了就必须立刻翻译成大白话。

依据参照 `01_行业专业知识/1_基础理论/` 各文件的"表达原则"，那几份原文反复强调：讲关系和作用，少堆玄词。

**常见失败**：术语堆砌，自己觉得专业，用户听不懂就划走。

---

### 第 4 步｜给解决方案

**做什么**：给一个她今天就能做的事。

**可以给**
- 一个观察方向（这段时间注意什么）
- 一个判断依据（怎么自己看）
- 一个调整动作（具体、小、可执行）
- 一个节奏建议（什么时候适合动）

**不能给**
- 保证应验的预测
- 必须花钱才能解决的暗示
- 恐吓式后果
- 符咒实操类内容

口径依据：`01_行业专业知识/6_经典与依据/6.5_安全边界与对外定位.md`

**关键**：方案要小。"调整心态"太大，"这周先别做重大决定"刚好。

---

### 第 5 步｜引导互动

**做什么**：给一个低门槛的回应动作。

**按目的选**

| 目的 | 引导方式 |
|---|---|
| 提高评论 | 问一个她能答的问题（你是哪一种？） |
| 提高收藏 | 明说这条值得存（存着，遇到时看） |
| 引导私信 | 留一个她想确认的口子 |
| 引导购买 | 指向课程/咨询，一句话，不硬推 |

**常见失败**
- 求赞求关注，没有理由
- 问题太大答不上来（你怎么看命运？）
- 硬广插入太早，前面的信任白建

## 三、按平台变形

### 抖音短视频（30-60 秒）

```
0-3 秒    共鸣（钩子）
3-10 秒   认知差
10-35 秒  解释
35-50 秒  方案
50-60 秒  互动
```

解释部分给最多时间，那是留人的核心。

---

### 小红书图文

```
首行     共鸣 + 关键词
正文     认知差 → 解释 → 方案（分点，每点一行）
结尾     互动 + 标签
```

要点：多用换行和分点，手机上视觉不能密。

---

### 公众号长文

```
开头     场景铺垫（可以慢）
第一段   共鸣
中段     认知差 + 解释（这里可以深，是公众号的优势）
后段     方案
结尾     互动 + 软性引导
```

公众号是唯一能把专业度讲透的地方，适合承接深度信任。

---

### 私域成交文案

结构不同，不走这五步：

```
1. 说出她的具体处境（不是泛化人群）
2. 指出她自己解决不了的原因
3. 说明你能提供什么（具体到形式和交付）
4. 降低决策风险（时长、价格、流程透明）
5. 给一个明确的下一步动作
```

关键差别：私域是一对一，不需要制造认知差，需要**给确定感**。

详见 `04_文案案例库`。

## 四、结构自检

发布前过一遍：

- [ ] 第一句是在说用户，不是在说我
- [ ] 有没有一个她没想到的角度
- [ ] 专业解释有没有翻译成大白话
- [ ] 方案是今天就能做的吗
- [ ] 结尾有明确的下一步
- [ ] 全篇有没有绝对化承诺
- [ ] 有没有恐吓式表达
- [ ] 术语是不是超过一个
