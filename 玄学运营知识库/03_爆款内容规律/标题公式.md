# 标题公式

## 这份文件做什么

标题决定打开率。内容再好，标题不行就没人看到。
这里存**可直接套用的句式**，写标题时不要从零想，从这里挑。

**标记说明**：`[待补充]` = 需要真实数据填的坑；`[待核实]` = 需要你用实测验证的判断。

---

## 一、核心公式

### 公式 1｜为什么 + 现象 + 解释

```
为什么有些人越努力越穷？古人早已发现原因
```

**拆解**
- `为什么` —— 触发好奇，大脑自动想找答案
- `现象` —— 用户身上正在发生的事，不是抽象概念
- `解释` —— 暗示有答案，而且答案有来头

**适用**：认知差类内容
**平台**：抖音、公众号最强

**变体**
- 为什么越懂事的人，越容易被消耗？
- 为什么你努力了三年，还是原地踏步？
- 为什么有些人天生就招人喜欢？

---

### 公式 2｜如果你出现XX，说明XX

```
如果你出现XX，说明XX
```

**拆解**
- `如果你` —— 点名，让人对号入座
- `出现XX` —— 具体可感的信号，越日常越好
- `说明XX` —— 给一个解释框架，让混乱的感受有了名字

**适用**：自检类、信号类
**平台**：全平台通用，抖音完播率最高

**变体**
- 如果你最近总是睡不醒，可能不是累
- 如果你身边突然有人离开，说明你在换阶段
- 如果这三件事同时发生，你正在转运

---

### 公式 3｜数字 + 特征 + 归类

```
这三种人，天生财运不差
```

**拆解**：数字给确定感，归类让人想确认自己在不在里面
**适用**：盘点类、特征类
**注意**：数字控制在 3-5，超过记不住

---

### 公式 4｜否定常识

```
八字里最不该改的，就是这个
```

**拆解**：先立一个用户以为的常识，再推翻
**适用**：专业度展示
**注意**：推翻的必须是真常识，不能自己造一个来打

---

### 公式 5｜时间节点 + 提醒

```
接下来这段时间，这几件事先别做
```

**拆解**：时间给紧迫感，提醒给价值
**注意**：不要承诺具体事件会发生，只讲节奏与倾向

---

### 公式 6｜身份点名

```
命里带财的女人，往往有这几个共同点
```

**拆解**：直接点出画像，让目标用户觉得在说自己
**适用**：对准 `02_用户需求与心理/用户画像.md` 里某一细分型时用

---

### 公式 7｜对比型

```
同样的八字，为什么有人过得好有人过得差
```

**拆解**：制造张力，用户想知道差别在哪
**适用**：讲结构、讲变量

---

### 公式 8｜一句话反问

```
你有没有想过，顺不顺其实跟节奏有关
```

**拆解**：不给答案，只给一个新角度
**适用**：公众号、小红书，抖音偏弱（不够直接）

---

## 二、好标题的三个必要条件

缺一个就废：

1. **有"我"** —— 用户能对号入座，不是在讲别人的事
2. **有具体** —— 具体到能想象的画面，不是"运势""能量""磁场"
3. **有未完成** —— 留一个没讲完的口子，让人必须点开

自检：把标题读一遍，问自己"这句话是在说我吗"。如果不是，重写。

---

## 三、平台差异

| 平台 | 标题长度 | 语气 | 重点 |
|---|---|---|---|
| 抖音 | 短，10-15 字 | 直接、口语 | 前 3 字就要抓住 |
| 小红书 | 中，15-25 字 | 像朋友说话，可带 emoji | 关键词要能被搜到 |
| 公众号 | 长，20-30 字 | 可以有余味 | 引发转发欲 |
| 私域 | 不用标题 | 一对一口吻 | 直接进入她的处境 |

`[待核实]` 各平台字数的实际表现，用你账号数据验证。

---

## 四、这些标题不要写

### 绝对化承诺
- ❌ 照做必发财
- ❌ 一定能遇到正缘
- ❌ 三天见效

### 恐吓式
- ❌ 今年有大劫
- ❌ 不处理毁一辈子
- ❌ 这种八字注定婚姻失败

### 平台风险词
玄学内容属于敏感区，用词直接影响推流。
`[待核实]` 需要用小号实测哪些词会限流，把结果记在下面：

- 疑似限流词：[待补充]
- 安全替代说法：[待补充]

```
- 平台：
- 播放/曝光：
- 完播率/点击率：
- 用了哪个公式：
- 为什么成了：（自己的判断）
```
