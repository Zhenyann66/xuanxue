# 开头钩子

## 这份文件做什么

标题决定有没有人点进来，开头决定点进来的人留不留。
短视频前 3 秒划走，后面写得再好都是白写。

**标记说明**：`[待补充]` = 需要真实数据填的坑。

---

## 一、核心原则

### 前三秒

**不要介绍自己。**

**不要：**
```
大家好我是某某老师。
```

**应该：**
```
如果你最近总感觉不顺，
可能不是运气不好。
```

### 为什么

用户刷到你的时候，跟你没有任何关系，凭什么听你自我介绍。
她只关心一件事：**这条跟我有关吗。**

所以第一句话的任务不是建立身份，是**建立关联**。

身份什么时候讲？等她已经听进去了，在中段或结尾顺带一句，或者交给主页和人设。

---

## 二、钩子类型

### 1｜处境点名

直接描述她此刻的状态。

```
你有没有过那种感觉，明明什么都没做错，但就是不顺。
```

**原理**：被说中的瞬间，人会停下来
**适用**：几乎所有痛点类内容，最通用
**素材来源**：`02_用户需求与心理/用户痛点.md` 的情绪底色那一栏

---

### 2｜反常识

先否定她原本的理解。

```
不顺不是运气差，是你正在换节奏。
```

**原理**：认知冲突产生停留
**注意**：否定的必须是她真的相信的事，否则无效

---

### 3｜场景代入

给一个具体画面，不讲道理。

```
凌晨两点还醒着，手机翻来翻去，其实没什么可看的。
```

**原理**：画面比概念更快唤起共鸣
**适用**：情绪类、感情类内容
**注意**：细节要真，假细节一秒破功

---

### 4｜自检清单

给几个可对照的信号。

```
这三件事如果最近同时出现，你别急着焦虑。
```

**原理**：人无法抗拒对号入座
**适用**：信号类、特征类

---

### 5｜悬念前置

把结论的一半先抛出来。

```
有件事我一般不太讲，因为很容易被误解。
```

**原理**：信息缺口驱动继续看
**注意**：后面必须真的有东西，否则掉粉

---

### 6｜提问直击

问一个她正在想的问题。

```
你是不是也在想，还要熬多久。
```

**原理**：问题就是她的内心独白
**素材来源**：`02_用户需求与心理/高频问题.md`，直接抄原话

---

### 7｜否定预期

先排除她以为你要说的话。

```
我不会跟你说顺其自然，那句话没用。
```

**原理**：她被这句话安慰过无数次，否定它等于站到她这边
**适用**：建立信任，私域尤其有效

---

## 三、按平台调整

| 平台 | 开头要求 | 长度 |
|---|---|---|
| 抖音 | 第一句就是钩子，可配画面停顿 | 一句话，不超过 15 字 |
| 小红书 | 首行要有信息量，兼顾搜索关键词 | 1-2 行 |
| 公众号 | 可以慢半拍，用场景铺垫 | 一小段 |
| 私域 | 直接说她的事，不要任何铺垫 | 一句话 |

---

## 四、钩子失效的常见原因

- **太抽象** —— "能量场不稳定"，用户没感觉
- **太笼统** —— "很多人都有这个问题"，不是在说我
- **先讲理论** —— 一上来解释什么是十神
- **先自我介绍** —— 最常见的失败
- **语气像上课** —— 用户是来被理解的，不是来被教育的
- **钩子和后文无关** —— 骗进来，完播反而更差

---

## 五、三秒之后

钩子只负责留人，留下之后要立刻给推进。

**3 秒**：点名她的处境
**3-10 秒**：给一个她没想到的角度
**10 秒后**：进入解释

如果 10 秒还在重复"你是不是很焦虑"，人就走了。

完整推进方式见 `内容结构.md`。
