# 用户痛点

## 这份文件做什么

这是整个知识库里对文案质量影响最大的一份。

核心判断：**用户问的问题，不是她真正想解决的问题。**
文案如果去回答表层问题，就变成科普；回应真实诉求，才会被转发、被留言、被私信。

**标记说明**：`[待补充]` = 需要用真实案例填的坑。

---

## 一、根本认知

### 用户真正想解决的

不是想知道八字。

而是：

- 我未来有没有机会？
- 我的选择是不是正确？
- 为什么别人比我顺？

### 这三句话的分量

几乎所有玄学咨询，剥到底都是这三问之一。
八字、紫微、六爻、风水，在用户眼里只是**工具**，她要的是**确定感**。

写文案时的判断标准：
> 这条内容有没有在回应这三问？如果只是在讲十神是什么，就是自嗨。

---

## 二、表层提问 → 真实诉求 对照表

**这张表是本文件的核心资产**，写文案直接查。

| 用户表层怎么问 | 真实想解决的 | 情绪底色 | 文案切入角度 |
|---|---|---|---|
| 我的八字怎么样？ | 我这辈子是不是没希望了 | 怕被判死刑 | 先给结构，再给可动空间 |
| 我什么时候能结婚？ | 我是不是有问题、会不会没人要 | 自我怀疑 | 谈她的关系模式，不谈期限 |
| 他是不是我的正缘？ | 我该不该继续耗下去 | 耗不起又怕放错 | 谈这段关系的运作方式 |
| 我适合做什么工作？ | 我到底有什么价值 | 被否定太久 | 谈优势怎么用出来 |
| 今年财运好不好？ | 我的辛苦什么时候有回报 | 不甘心 | 谈节奏，不承诺数字 |
| 该不该换工作/创业？ | 我不敢自己承担这个决定 | 怕担责 | 给判断依据，把决定权交回 |
| 为什么我总是遇到烂人？ | 我是不是命里注定 | 宿命感、无力 | 谈模式可识别、可打断 |
| 我的孩子怎么样？ | 我怕自己耽误了孩子 | 内疚 | 谈孩子的特点与相处方式 |
| 家里风水要不要调？ | 我想要一件马上能做的事 | 失控中求掌控 | 给具体可执行动作 |
| 我是不是命不好？ | 求一个人告诉我不是 | 羞耻、孤立 | 先接住情绪，再讲结构 |
| [待补充] | | | |

### 用法

- 写选题：从左列挑一句当标题
- 写正文：按第二列展开，第一列只当开场钩子
- 定语气：看第三列，语气对不上，内容再准也没用
- 落笔：照第四列，别越界

## 三、痛点分层

每个痛点拆三层，文案要打到第二、三层。

### 第一层｜表层问题
用户说出口的那句话。特征：具体、封闭、要一个答案。

### 第二层｜真实诉求
她真正想拿到的东西。特征：关于自我价值、关于确定感、关于能不能掌控。

### 第三层｜情绪底色
支撑这个提问的情绪。常见的几种：
- **怕来不及** —— 年龄、时机、错过
- **不甘心** —— 凭什么别人比我顺
- **自我怀疑** —— 是不是我有问题
- **怕担责** —— 不敢自己做决定
- **羞耻** —— 说不出口，只能问陌生人
- **无力** —— 努力过了，没用

情绪底色决定文案的**语气**，这一层错了，整条内容会让人反感。

## 五、痛点不等于恐惧

行业里最常见的做法是放大恐惧，短期有效，长期毁号。

**踩线做法**（不用）：
- 你今年有大劫
- 不处理会影响一辈子
- 这个八字婚姻必败

**替代做法**（用）：
- 指出结构里容易卡住的地方，说明为什么
- 给出可以观察和调整的方向
- 把判断依据讲清楚，让用户自己得结论

参照 `01_行业专业知识/6_经典与依据/6.5_安全边界与对外定位.md`，那份文件已经写明不做恐吓式结论。

## 六、怎么填 `[待补充]`

每次咨询结束后补一条，格式：

```
- 表层问的：（原话照抄）
- 实际在意的：（咨询中显露出来的）
- 情绪：（她说这话时的状态）
- 后来怎么回应的：（有效/无效）
```

积累 30 条以上，这份文件的价值会超过整个 01 文件夹。
